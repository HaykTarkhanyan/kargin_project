**Use match *stability* instead — it needs no external facts.** The same clip (`hBNHfoPXyME` @ 210s) returned `Chef 187 - Higher [2021]` on one run and `Dixon Miller - Guitarmaniac [2016]` on the next. Identical audio in, different answer out. A genuine fingerprint hit is deterministic, so a match that changes between runs is noise-driven by construction. Re-running and keeping only repeat matches filters false positives using nothing but the data itself — no release dates, no air dates, no assumptions about the archive.
