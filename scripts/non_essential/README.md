# non_essential/

Maintained dev/QA tooling that is not needed to operate the project.

| Script | What it does / when to re-run |
|---|---|
| `apply_collection_candidates.py` | Turns the `include=y` rows of `data/collections_candidates.csv` into `data/corrections.csv` rows for the `collections` column, merging several themes for one sketch into a single `;`-joined value. Re-run after editing the ticks, then apply with `scripts/apply_corrections.py --write`. Added 2026-09-12. |
| `build_similarity_report.py` | HTML report over the artifacts in `data/embeddings/`: validation stats, the audio-fingerprint duplicate cross-check, and each sketch's nearest neighbours, for eyeballing similarity quality. Reads saved artifacts only, never calls the API. Re-run after a new embedding run. Added 2026-09-08 with the embeddings work (DECISIONS #12). |
| `build_text_annotation_pilot_report.py` | Builds the side-by-side HTML report (`data/text_annotations_pilot/report.html`) comparing flash3 vs flash38 pilot annotations, plus spend totals from the ledger. Re-run after adding pilot rows. Added 2026-09-07 for the text-annotation model pilot. |
| `compare_embedding_variants.py` | Compares two embedding variants from `scripts/embed_annotations.py` (for example full vs stripped input) on duplicate-pair recovery, topic agreement, score spread and neighbour coverage. Reads saved artifacts only. Re-run when trying a different embedding input. Added 2026-09-08 with the embeddings work (DECISIONS #12). |
| `parse_google_forms.py` | Turns the raw Google Forms captures in `data/google_forms/<n>/` (Playwright dumps of `FB_PUBLIC_LOAD_DATA_` + page HTML) into `form.json`, `form.md`, `page_text.txt` and downloads the question/option images at full size. Re-run after re-capturing a form. See `data/google_forms/README.md`. Added 2026-09-11. |
| `report_usage.py` | Pulls the Firestore `events` collection (site + Telegram bot usage) into `data/usage/` — raw dump, JSON summary, HTML report. Re-run any time you want to know what people searched for. `--from-dump <path>` re-aggregates without re-reading Firestore. Needs `--group firebase` and the SA key at `internal/firebase-sa-kargin-archive.json`. Added 2026-09-11. |
| `scout_channels.py` | Maps the YouTube channels that upload Kargin material, to find sketches missing from the archive. Seeds come from `data/channel_scout/seeds.json` (hand-entered links and channels) and `pw_search_hits.json` (Playwright YouTube search scrape). Lists every upload of each channel through the Data API, keeps the ones with a Kargin signal (all of them for a dedicated channel), and writes `channels.json`, `channels_rejected.json`, `videos.json` and `videos.csv`. Metadata only, no downloads, free quota. Re-run after adding seeds or a new search scrape. Added 2026-10-27. |
| `collapse_pool.py` | Plan step M2: merges exact copies in the multi-sketch pool before the full-audio download (Kaset tapes with the same number and a duration within 10 s), keeps one per group by the Q8 ranking, writes `data/compilations/pool_groups.csv` and `pool_download_ids.txt`. Re-run after the pool changes. Added 2026-11-03. |
| `fetch_candidate_status.py` | Plan step A5's data: YouTube Data API status + contentDetails for every candidate and pool video (public, embeddable, blocked in AM/DE, age-restricted, HD) into `data/candidates/status.csv`; a video the API no longer returns is written `gone`. ~45 quota units. Re-run before choosing copies if time has passed. Added 2026-11-03. |
| `gate_unclear.py` | DECISIONS #22: samples up to 8 unmarked uploads per channel (`sample`), then decides per channel from how often they match the archive (`decide` → `data/candidates/unclear_gate.csv`: keep / skip / triage). The sample is append-only and sized to the channel (8/16/24), grouped by channel_id, and matching uses the same per-sketch rule as `match_candidates.py`. Re-run after new candidates or a new archive index. Added 2026-11-03, revised after review the same day. |
| `map_compilations.py` | Plan steps 0.6 and M4/M5: matches whole multi-sketch videos against the archive index, confirms each matched stretch (density shortcut, windowed cross-correlation in the ambiguous band, sample-level check for short reel pieces; fan clips must be ≥ 50% covered), and writes a timeline with `unknown` gaps (`data/compilations/timeline_<set>.csv`) plus an audit of the shortcut (`audit_<set>.csv`). Hit caps scale with length; stretches are full extents. `--set archive` for the archive's own compilations, `--set pool` for the fan pool. Needs the `match` group. Added 2026-11-03. |
| `match_candidates.py` | Plan steps A4 + A5: turns `matches_archive.jsonl` / `matches_self.jsonl` into one verdict per candidate (have / new / new* / multi / gated_out / unavailable / no_clip), scoring per archive sketch (all stretches on one sketch summed, duplicates merged, coverage measured on the sketch's timeline), clusters copies (links must cover half the clip), and picks each cluster's canonical copy by the Q8 ranking → `data/candidates/matches.csv`. Re-run after any new matches. Added 2026-11-03. |
| `screen_audio.py` | Downloads screening audio for the archive extension (plan A3/M3): the first 90 s of each standalone candidate (`--set candidates`) or the whole audio of each compilation, episode or tape (`--set pool`), at ~48 kbps, into gitignored folders. Paced, resume-safe, stops on YouTube's bot check, and records removed/private/age-restricted uploads in `<set>_failures.csv`. Re-run to resume after a bot-check stop. Added 2026-11-03. |
| `triage_ui.py` | Plan step A6: the owner's local triage page (127.0.0.1:5056, `review` group) over `matches.csv`, one item per cluster of copies, keyboard-driven, each save appended to `data/candidates/decisions.csv` (latest row per cluster wins). `--decisions` points it elsewhere for tests. Added 2026-11-03. |
| `triage_candidates.py` | Sorts the channel-scout videos into standalone candidates (`data/candidates/candidates.csv`), the multi-sketch pool (`data/compilations/pool.csv`, plus the archive's own visually-flagged compilations) and skips with a reason (`data/candidates/skipped.csv`), applying the scope in DECISIONS #19. No API calls. Re-run after a new scout run or a scope change. Added 2026-11-03. |
| `seed_collection_candidates.py` | Proposes collection members by searching `data/visual_annotations/` and `data/text_annotations/` per theme, writing `data/collections_candidates.csv` with the phrase that matched as evidence and a blank `include` column to tick. Splits strong evidence (the phrase names the situation) from weak (the word merely appears), and keeps existing ticks when re-run. Re-run after adding a theme to `THEMES` in the script. Added 2026-09-12. |
