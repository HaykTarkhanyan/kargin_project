# non_essential/

Maintained dev/QA tooling that is not needed to operate the project.

| Script | What it does / when to re-run |
|---|---|
| `apply_collection_candidates.py` | Turns the `include=y` rows of `data/collections_candidates.csv` into `data/corrections.csv` rows for the `collections` column, merging several themes for one sketch into a single `;`-joined value. Re-run after editing the ticks, then apply with `scripts/apply_corrections.py --write`. Added 2026-09-12. |
| `build_similarity_report.py` | HTML report over the artifacts in `data/embeddings/`: validation stats, the audio-fingerprint duplicate cross-check, and each sketch's nearest neighbours, for eyeballing similarity quality. Reads saved artifacts only, never calls the API. Re-run after a new embedding run. Added 2026-09-08 with the embeddings work (DECISIONS #12). |
| `build_text_annotation_pilot_report.py` | Builds the side-by-side HTML report (`data/text_annotations_pilot/report.html`) comparing flash3 vs flash38 pilot annotations, plus spend totals from the ledger. Re-run after adding pilot rows. Added 2026-09-07 for the text-annotation model pilot. |
| `compare_embedding_variants.py` | Compares two embedding variants from `scripts/embed_annotations.py` (for example full vs stripped input) on duplicate-pair recovery, topic agreement, score spread and neighbour coverage. Reads saved artifacts only. Re-run when trying a different embedding input. Added 2026-09-08 with the embeddings work (DECISIONS #12). |
| `parse_google_forms.py` | Turns the raw Google Forms captures in `data/google_forms/<n>/` (Playwright dumps of `FB_PUBLIC_LOAD_DATA_` + page HTML) into `form.json`, `form.md`, `page_text.txt` and downloads the question/option images at full size. Re-run after re-capturing a form. See `data/google_forms/README.md`. Added 2026-09-11. |
| `report_usage.py` | Pulls the Firestore `events` collection (site + Telegram bot usage) into `data/usage/` — raw dump, JSON summary, HTML report. Re-run any time you want to know what people searched for. `--from-dump <path>` re-aggregates without re-reading Firestore. Needs `--group firebase` and the SA key at `internal/firebase-sa-kargin-archive.json`. Added 2026-09-11. |
| `seed_collection_candidates.py` | Proposes collection members by searching `data/visual_annotations/` and `data/text_annotations/` per theme, writing `data/collections_candidates.csv` with the phrase that matched as evidence and a blank `include` column to tick. Splits strong evidence (the phrase names the situation) from weak (the word merely appears), and keeps existing ticks when re-run. Re-run after adding a theme to `THEMES` in the script. Added 2026-09-12. |
